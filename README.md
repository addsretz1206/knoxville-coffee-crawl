# Knoxville Coffee Crawl

An interactive [StoryMapJS](https://storymap.knightlab.com/) tour of five highly rated coffee shops near the University of Tennessee and downtown Knoxville.

## Editing
- Slide text, locations, and zoom live in `storymap.json`.
- To add a photo, put it in `images/` and set that slide's `media.url` (e.g. `"images/capybara.jpg"`), plus `media.credit` and `media.caption`.

Map data &copy; OpenStreetMap contributors.
